# 🖥️ Sistema de Ofimática para el Hogar

---

## 📖 Introducción

El presente proyecto tiene como objetivo el diseño de un sistema informático destinado a un entorno de uso doméstico y de oficina, orientado a satisfacer las necesidades de productividad, comunicación y trabajo colaborativo.

Para ello, se realizó un análisis de los requerimientos técnicos de las principales aplicaciones de ofimática utilizadas en la actualidad, con el fin de seleccionar componentes de hardware compatibles, equilibrados y con una adecuada relación entre costo y rendimiento.

---

## 🎯 Objetivos

* Diseñar un sistema informático orientado al uso de oficina y hogar.
* Analizar los requisitos recomendados de cada aplicación.
* Seleccionar componentes compatibles entre sí.
* Elaborar un presupuesto detallado basado en precios reales del mercado argentino.
* Justificar técnicamente la elección de cada componente.

---

## 💻 Software Analizado

Durante el desarrollo del proyecto se estudiaron los requerimientos de los siguientes programas:

* 🌐 Google Chrome
* 🎬 VLC Media Player
* 📧 Mozilla Thunderbird
* 📄 LibreOffice
* 🎥 Zoom Workplace
