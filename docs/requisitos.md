# Requisitos

## Tabla comparativa de requisitos para cada software, se usara en la propuesta final windows 11

| Software | Sistema Operativo | Procesador | Memoria RAM | Almacenamiento | Otros requisitos |
|:---|:---|:---|:---|:---|:---|
| **Google Chrome** | Windows 10 o superior / Windows Server 2016 o superior | Intel Pentium 4 o superior compatible con SSE3 | No especificado | No especificado | Compatible con arquitectura moderna |
| **VLC Media Player** | Windows 10 (versión 14393.0 o posterior) y Windows 11 | No especificado | No especificado | No especificado | Se recomienda conexión a Internet y altavoces |
| **Mozilla Thunderbird** | Windows 10 o superior | CPU de doble núcleo de 1.5 GHz o superior | 2 GB mínimo (4 GB recomendados) | Entre 200 MB y 500 MB libres | - |
| **LibreOffice** | Windows Server 2012–2022, Windows 10 y Windows 11 | Procesador compatible con Pentium | 256 MB mínimo (512 MB recomendados) | Hasta 1,5 GB libres | Resolución mínima de 1280 × 800 píxeles |
| **Zoom** | Windows de 64 bits | Procesador de 4 núcleos a 2,5 GHz o superior | 16 GB | No especificado | CPU de 64 bits |
